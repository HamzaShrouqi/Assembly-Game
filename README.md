# Two-Player Assembly Game

A two-player game prototype developed using **8086 Assembly Language** and **EMU8086** as a university project.

## Technologies
- 8086 Assembly Language
- EMU8086 Emulator
- DOS and BIOS Interrupts

## Implemented Features
- Two-player readiness system
- Keyboard input handling
- Input validation and error messages
- Player health display (visual only)
- Colored player block rendering
- Central wall rendering
- Screen manipulation using BIOS interrupts

## Project Status

This project is an early game prototype. Core gameplay mechanics, including player movement, shooting, collision detection, and health reduction, were not completed.

## Running the Project

1. Open the `.asm` source file in EMU8086.
2. Assemble the source code.
3. Run the program in the emulator.
